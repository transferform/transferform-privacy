TransferForm — Política de Privacidade

Última atualização: 25 de agosto de 2026

1. Dados acessados pela extensão

Dependendo da utilização da extensão, o TransferForm pode acessar:

  • informações inseridas pelo usuário em campos de formulário compatíveis;
  • conteúdo da página da Web necessário para o funcionamento da extensão;
  • informações de identificação pessoal que o próprio usuário insira em campos de formulário compatíveis.

O TransferForm não processa intencionalmente campos de senha (password) nem arquivos (file).

2. Finalidade do uso dos dados

Os dados acessados pelo TransferForm são utilizados exclusivamente para a finalidade principal da extensão: auxiliar o usuário na transferência e no preenchimento de informações em formulários compatíveis.

A extensão não utiliza os dados do usuário para finalidades não relacionadas à sua função principal.

3. Processamento local

O TransferForm funciona 100% localmente no navegador do usuário.

Os dados acessados ou processados pela extensão não são enviados para servidores externos, APIs, serviços de terceiros ou qualquer infraestrutura controlada pelo desenvolvedor.

4. Venda ou transferência de dados

O TransferForm não vende dados do usuário.

O TransferForm não transfere, compartilha ou divulga dados do usuário a terceiros.

Os dados permanecem no ambiente local do navegador e são utilizados somente quando necessário para fornecer a funcionalidade da extensão.

5. Publicidade, perfilamento e crédito

O TransferForm não utiliza dados do usuário para publicidade direcionada ou perfilamento.

O TransferForm não utiliza nem transfere dados do usuário para determinar credibilidade, capacidade de crédito, elegibilidade para empréstimos ou qualquer outra finalidade relacionada a crédito ou empréstimos.

6. Armazenamento de dados

O TransferForm não envia dados do usuário para armazenamento externo.

A extensão não mantém uma base de dados externa contendo informações dos usuários.

7. Segurança e privacidade

Como o processamento ocorre localmente no navegador, os dados tratados pela extensão não são transmitidos ao desenvolvedor.

O usuário deve utilizar a extensão somente em páginas e formulários nos quais confia e deve observar as práticas de privacidade e segurança dos próprios sites que visita.

8. Alterações nesta Política de Privacidade

Esta Política de Privacidade poderá ser atualizada caso o funcionamento do TransferForm ou suas práticas de tratamento de dados sejam modificados.

A data da última atualização será alterada sempre que houver uma mudança relevante nesta política.

9. Contato

Em caso de dúvidas sobre esta Política de Privacidade ou sobre o funcionamento do TransferForm, o usuário poderá entrar em contato com o desenvolvedor por meio das informações de contato disponibilizadas na página da extensão na Chrome Web Store.
